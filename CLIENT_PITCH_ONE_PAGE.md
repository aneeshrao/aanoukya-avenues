# Aanoukya Avenues - One-Page Website Pitch

Reference site in Framer: `https://minimal-products-945796.framer.app/`

---

## Goal

Build a premium, high-performance website that matches Aanoukya Avenues' brand quality and supports long-term business growth.

---

## Why Not Framer-Only

Framer is great for quick visual pages. For this requirement, we need deeper control.

- Premium animation quality needs stronger customization control
- Growing business content needs a more flexible CMS structure
- SEO and schema control are stronger in a custom build
- Complex workflows/integrations work better when built natively
- Third-party tool dependency can increase cost over time

---

## Proposed Approach

Custom-coded website from scratch with a secure backend and admin CMS.

- Better animation quality and design control
- Better long-term scalability
- Better control over content, SEO, and integrations
- Better ownership of code and data
